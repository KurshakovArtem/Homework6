# Домашнее задание 6

## ООП: композиция, наследование и интерфейсы

### Задача №1. Nullable

Доработайть первую задачу из предыдущей лекции так, чтобы в классе `Post` некоторые поля были `Nullable` (на выбор).

#### Итог
1. Data-класс `Post`.
2. Внутри `Post` могут быть `Nullable`-свойства.
3. `WallService`, который хранит посты в массиве.

### Задача №2. Attachments

Следующая задача: разобраться с вложениями у постов - `attachments`

Возможны два варианта:
* сделать `Attachment` интерфейсом,
* сделать `Attachment` абстрактным классом.

В обоих вариантах нужно добавить в `Attachment` поле `type`, а после описать наследников Attachment, которые уже будут хранить специфичные данные (фото, аудио, видео).

Поскольку типов вложений очень много, достаточно выбрать для реализации любые 5.

Можно определить фиксированную иерархию типов (количество типов вложений фиксировано).
